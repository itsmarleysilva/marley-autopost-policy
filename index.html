Marley Autopost – Privacy Policy

Last updated: October 22, 2026

Marley Autopost is a private, personal tool made and used only by Marley Silva. It uploads and schedules Marley's own videos to Marley's own accounts on YouTube, TikTok and Instagram. It is not offered to the public and has no other users.

What data the app uses

The app only uses the sign-in permission (access token) that Marley grants for her own accounts, so it can upload her videos with their titles, descriptions and scheduled times. It does not collect, store, sell or share any information about anyone else, and it has no ads, tracking or analytics.

Where it is stored

Access tokens are stored privately on Marley's own computer and in her private storage. They are never shared with anyone.

YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access can be removed at any time on the Google security settings page.

TikTok and Instagram

For TikTok and Instagram, the app uses only the official TikTok Content Posting API and the Instagram API to publish Marley's own videos to her own accounts. Access can be removed at any time in each app's settings.
